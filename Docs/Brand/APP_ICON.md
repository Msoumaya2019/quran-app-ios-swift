# Icône de l’application native

Créée avec l’outil intégré ImageGen. Source originale conservée dans `AppIcon-source.png`. Export technique iOS : `../../Resources/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`, PNG RGB opaque 1024 × 1024 ; redimensionnement proportionnel sans recadrage. Coins appliqués par iOS. Catalogue `AppIcon` sélectionné explicitement dans les réglages Xcode générés.

Direction : Coran ouvert ivoire, arche/spine dorées, fond vert profond. Sans texte ni écriture arabe, symbole unique lisible à petite taille. Aucune modification de l’identité des fichiers ou du dépôt Expo.

## Prompt final utilisé

Use case: logo-brand. Create a finished native iPhone app icon for a premium French Quran learning application. One single 1024 by 1024 square production asset, opaque RGB PNG, full bleed solid deep forest green (#294F3D) background all the way to all four square edges. A perfectly centered very simple elegant open Quran/book symbol in warm ivory (#FCFBF8), with a restrained matte gold (#C59A50) central spine and a single graceful minimal Islamic pointed arch subtly integrated above the book. Flat vector-like graphic, smooth crisp balanced curves, medium-weight clean strokes and large recognizable silhouette, exquisite optical symmetry, generous clear space, instantly legible as a tiny home-screen icon. Calm, timeless, spiritual and sophisticated. No text, no Arabic writing, no letters, no numbers, no watermark, no mockup, no phone, no external border, no rounded outer corners, no shadow, no texture, no 3D, no scenery, no extra ornaments, no stars or crescents. The icon itself fills the entire square image; iOS will apply the corner mask. Deliver just this one icon, not a presentation sheet.
